# المحافظ — لعبة بناء مدينة الكويت

لعبة بناء مدن عربية بعرض Isometric ثلاثي الأبعاد على خريطة مدينة الكويت الحقيقية. تبدأ **مساعداً للمختار** في حي من أحياء الكويت، وتكبر منطقتك بإرضاء الناس حتى تصير **مختار المنطقة** ثم **المحافظ**.

## طريقة اللعب

1. اضغط **«اختر الحي وابدأ»** واختر حياً: اليرموك أو العديلية أو السرة، أو المنطقة الحرة لكل المدينة.
2. ابنِ البيوت والمحلات من الأزرار يمين الشاشة، وارصف الطرق، ووفّر الكهرباء والماء.
3. اضغط على المبنى لتجمع دخله، أو اضغط زر **«اجمع»** في الأسفل.
4. حافظ على رضا الناس لتزيد السكان وتترقّى.

### الألقاب

| اللقب | عدد السكان |
| --- | --- |
| مساعد المختار | من البداية |
| مختار المنطقة | ١٥٬٠٠٠ ساكن |
| المحافظ | ١٠٠٬٠٠٠ ساكن |

الهدف بعدها: **مليون ساكن**. القصة تمر بأربع حقب، وكل حقبة تفتح مباني ومعالم جديدة: الاستقلال ١٩٦١، ثم طفرة النفط (سوق المباركية واستاد جابر)، ثم الكويت الحديثة (برج الحمراء ومجمع الأفنيوز ومركز جابر الثقافي)، ثم مدينة المليون.

كل ترقية تعطي مكافأة مالية مرة واحدة، ويظهر لها احتفال. اللقب ونسبة الرضا يظهران أعلى يسار الشاشة.

### المباني

- **ناطحات السحاب:** العمارات والمحلات وأبراج المكاتب تُرقّى حتى المستوى ٥. في المستويين ٤ و٥ تصير ناطحات سحاب.
- **الشاليهات:** تُبنى على البحر مباشرة فقط.
- **معالم الكويت:** أبراج الكويت، والمسجد الكبير، وبرج التحرير، وقصر السيف، وبرج بوبيان، وبرج الحمراء، ومجمع الأفنيوز، ومركز جابر الثقافي، وسوق المباركية، واستاد جابر الدولي. الاستاد يضاعف أثر بطولات كرة القدم.
- **تأثير الجيران:** الحديقة بجانب البيوت ترفع دخلها، والسوق القريب يرفعه أيضاً، والمحطة بجانب السكن تخفضه. والمحلات تكسب أكثر عندما تحيط بها البيوت.

### الرضا والسكان والدخل

- **الخدمات:** كلما كبرت المنطقة احتاجت مدارس ومستوصفات وشرطة وإطفاء وحدائق تكفي سكانها. النقص يُنزل الرضا، ويمكن متابعة نسبة التغطية في لوحة **المستشارون**.
- **مصاريف المعيشة:** في لوحة **الميزانية** خمسة بنود يحددها المحافظ: السكن والإيجارات، والتعليم، والصحة، والكهرباء والماء، والنقل. رفعها يزيد دخل الصندوق، لكن الرضا ينزل والسكان يغادرون. ويمكن ضبط زيادة سنوية تلقائية (٢٪ أو ٥٪ أو ١٠٪).
- **التقرير السنوي:** في نهاية كل سنة تُقاس أرقام السنة: عدد السكان ونسبة نموه، والرضا، ومؤشر الغلاء، والدخل والمصروف.
- **النتيجة:** الرضا المنخفض يقلّل دخل المباني، والسكان يغادرون المنطقة تدريجياً. والرضا العالي يجذب سكاناً جدداً.
- لكل مبنى سعر ومصروف شهري. الشوارع الرئيسية في الأحياء المخططة على البلدية.

### الكوارث والأزمات والقروض

- **الكوارث** تحدث تلقائياً وتظهر على الخريطة: حريق بلهب ودخان، وعاصفة رملية بغبار كثيف، وانقطاع كهرباء يطفئ الأنوار، وأمطار وسيول تغمر الشوارع. كل كارثة تخصم مبلغاً من الرصيد.
- **الأزمات العالمية** نادرة وتستمر شهوراً:
  - الأزمة الاقتصادية تخفض الدخل وتهدد البنوك والشركات.
  - الوباء العالمي يُخرج السكان ويمنع الفعاليات، والمستوصفات تخفف أثره.
  - الحرب الإقليمية تكلّف دفاعاً مدنياً كل شهر.
- يمكن إيقاف الكوارث والأزمات أو تجربتها من لوحة **الكوارث والأزمات**.
- إذا صار الرصيد بالسالب، خذ **قرضاً من البنك** في لوحة الميزانية (٢٠٠٠ أو ٥٠٠٠ أو ١٠٠٠٠ د.ك). الفائدة ١٢٪، والقسط يُخصم كل شهر تلقائياً، ويمكن السداد في أي وقت.

### المشاريع والفعاليات

من زر **المشاريع**:

- **مناطق نموذجية جاهزة:** ضاحية سكنية، أو مجمع تجاري، أو مركز خدمات. تُبنى كاملة بشوارعها في أقرب أرض فاضية.
- **فعاليات ورياضة:** بطولة كرة قدم، وماراثون الكورنيش، ومهرجان هلا فبراير، وحفلة وطنية. ترفع الدخل والرضا وتجذب السكان طوال مدتها، وتترك سمعة دائمة للمنطقة.

### الشركات والاستثمار

من زر **الشركات** (أسماء الشركات خيالية):

- **بنك الديرة:** وديعة بفائدة ١٠٪ سنوياً، وسندات بقيمة ٢٥٠ ألفاً أو مليون أو مليونين د.ك بفائدة ٧–٨٫٥٪، وقروض.
- **شركة المرسى العقارية:** مشاريع (٥٠ ألفاً، أو ٢٥٠ ألفاً، أو مليون) تعيد رأس المال بربح ٣٠–٦٠٪، وبعضها يسلّمك ضاحية جاهزة. وتعرض أيضاً سندات بفائدة ١٢٪.
- **دار الرأي للاستشارات:** عقد سنوي يخفّض المصاريف ١٥٪، ويرفع الرضا، ويقلّل خسائرك عند الإفلاس إلى النصف.
- **المخاطرة:** أي شركة قد تفلس، واحتمال ذلك أعلى بكثير في الأزمات الاقتصادية. عند الإفلاس تخسر جزءاً كبيراً من المبلغ، وتُغلق الشركة مدة.

### المناسبات والمكافآت

- **المناسبات:** العيد الوطني وعيد التحرير (أعلام وألعاب نارية)، ورمضان (إفطار جماعي إذا بنيت المسجد الكبير)، والعيد. كلها ترفع الرضا.
- **المكافآت:** مكافأة يومية تكبر مع الأيام المتتالية، ودخل أثناء الغياب.
- **الإنجازات وصورة المدينة:** شاشة إنجازات، وزر يلتقط صورة للمدينة لمشاركتها، وموسيقى خلفية على مقام الحجاز.
- **البداية:** شرح تفاعلي قصير لأول مرة، وكل حي يبدأ بنواة صغيرة من البيوت والخدمات.

### التحكم

- **السحب بإصبع واحد:** يحرّك الخريطة، والأرض تبقى تحت الإصبع تماماً.
- **إصبعان (قرص):** تكبير وتصغير، أو استخدم أزرار + و − يسار الشاشة.
- **عند اختيار أداة بناء:** الضغطة القصيرة تبني، والسحب يحرّك الخريطة.
- **أزرار الأسفل:** الميزانية، والمشاريع، والشركات، و«المزيد» الذي يجمع بقية اللوحات.

## الخريطة

الأرض مرسومة من ساحل مدينة الكويت الحقيقي (Natural Earth بدقة 1:10m، ملكية عامة) ضمن المربع 47.90°–48.10° شرقاً و29.285°–29.405° شمالاً: جون الكويت شمالاً، ثم الشرق ورأس عجوزة، وساحل السالمية شرقاً. اليرموك والعديلية والسرة في مواقعها الحقيقية تقريباً. في المنطقة الحرة تظهر الطرق الدائرية من الأول إلى الخامس، وطريق الجهراء وطريق المطار وطريق الفحيحيل، مرسومة بشكل تقريبي. دقة الساحل في حدود كيلومتر تقريباً، ولا توجد شوارع داخلية حقيقية. مخططات القطع داخل الأحياء تفسيرات قابلة للعب، وليست مخططات مساحية.

## التشغيل والتطوير

```sh
npm install
npm run dev        # http://localhost:8080
npm run typecheck
npm run test:game
npm run build
```

| المسار | المحتوى |
| --- | --- |
| `src/game/sim.ts` | منطق اللعبة: الاقتصاد، الرضا، السكان، مصاريف المعيشة، الألقاب، الحقب، الكوارث، الأزمات، المناسبات، الإنجازات، القروض، الفعاليات، المناطق النموذجية، الحفظ |
| `src/game/finance.ts` | الشركات: الودائع، السندات، المشاريع العقارية، الاستشارات، الإفلاس |
| `src/game/land.ts` | قناع اليابسة والماء من الساحل الحقيقي |
| `src/game/districts.ts` | مخططات الأحياء ومواقعها على الخريطة |
| `src/game/catalog.ts` | المباني وأسعارها وخصائصها |
| `src/game/three/` | العرض ثلاثي الأبعاد (Three.js): الكاميرا، السحب واللمس، المجسمات، النهار والليل |
| `src/components/` | الواجهة العربية: اللوحات، الشرح التفاعلي، الاحتفالات (`hud-panels.tsx`) |

يستخدم العرض كاميرا Orthographic بزاويتي 32.5° و45°، و17 مجسماً للمباني بثلاث درجات LOD، ومعالم كويتية، وحركة مرور وأشجار نخيل، وظلالاً ناعمة، ونوافذ تضيء ليلاً. إذا تعذّر WebGL تظهر نسخة ثنائية الأبعاد متوافقة ومُعلَّمة بوضوح.

الحفظ محلي في المتصفح، ولكل حي حفظ مستقل. تغيّرت الخريطة في هذه النسخة، فالمدن المحفوظة سابقاً تبدأ بأرض جديدة، ويبقى الرصيد والإعدادات.

تم الاختبار في Chromium مع WebGL برمجي فقط، وليس على معالج رسوميات جوال حقيقي، ولا يوجد قياس FPS. الأمر `npm test` فيه إخفاقات قديمة في اختبارات OG/PWA موجودة في الأصل.

## Unity / الجوال

راجع [unity/README.md](unity/README.md). المشروع يحتوي مجسمات procedural أصلية، وكاميرا URP/Cinemachine، ولمس، واقتصاداً مصاحباً مبسطاً، وحفظاً محلياً، واختبارات EditMode. **لم يتوفر هنا Unity Editor ولا ترخيص Unity ولا Android SDK ولا Xcode/توقيع iOS**، فلم يُتحقق من مولّد المشهد ولا التخطيط العربي ولا البناء الأصلي ولا أداء الأجهزة ولا الاختبارات داخل Unity. ليس تطبيقاً جاهزاً لأندرويد أو آيفون، ولا يتضمن الاقتصاد الجديد (الألقاب، القروض، الفعاليات، الشركات، الأزمات) الموجود في نسخة الويب.

لا أصول مدفوعة في أي من النسختين، ولا نشر للعبة الحية. المعالم تفسيرات procedural مبسطة، وليست نماذج واقعية أو مسوحات معمارية.
